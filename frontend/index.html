IA Gateway — Asistencia conversacional con IA local

Un asistente que responde en tiempo real usando un modelo de lenguaje que corre en tu propia red, listo para incorporarse a cualquier página.

Integrarlo en otra página

Capacidades

Lo que ofrece el asistente en esta versión.

Respuestas en tiempo real

El texto aparece a medida que el modelo lo genera. Podés detenerlo en cualquier momento.

Conversación persistente

El historial se conserva al recargar la página durante 24 horas desde el último mensaje.

Preparado para herramientas

El modelo puede usar herramientas externas habilitadas por configuración, con entradas validadas.

Privado por diseño

El modelo corre localmente y, por defecto, los registros no guardan el texto de las conversaciones.

Lectura de imágenes

Adjuntá una captura o la foto de un documento y el asistente responde sobre su texto.

Integración

El chat es un componente reutilizable: dos líneas lo agregan a cualquier página.

<script type="module" src="http://localhost:8000/widget/ia-chat-widget.js"></script>
<ia-chat-widget backend-url="http://localhost:8000" title="Asistente"></ia-chat-widget>

El origen de la página debe figurar en IA_GATEWAY_ALLOWED_ORIGINS. Para consumir la API directamente desde otro frontend, ver la documentación de la API y el README del proyecto.
